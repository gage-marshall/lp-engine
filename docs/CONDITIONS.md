# Condition lists (TERM_BIN) and the condition-op vocabulary

Generated by `tools/cond_ops.py` from `tmx_tbin.arc` (688 files, 2,920 records, 14769 conditions, 107 distinct ops).

Native code: `MapArc_LoadMergedEntryList` (0x206febc) opens `arc/tmx_tbin.arc`, reads each listed entry and calls `CondList_CollectPassingRecords` (0x206743c). Format and evaluation are documented in `tools/term.py`. A record is `{event id, priority, used-flag, 3 OR-groups of (op, a, b) conditions}`; the evaluator keeps only records whose priority is >= the best so far and, for each passing record, outputs `(event id, flag-used)`. Selection among the survivors is random among unused ones (`MapQueue_SelectRandomEntry`: shuffle, take the first whose used-flag is 0, else a random one that differs from the last picked).

**Scoped flag ids** (script cmds 0x55/0x59, TERM used-flags, ops 2/3/13/14/24/25/107/108, 229): `scope = (id >> 12) & 3` (0 = global flags, 1/2/3 = the per-heroine flag set of slot 0/1/2 = Manaka/Rinko/Nene), bit index `= (id & 0xfff) | ((id & 0x4000) >> 2)` in a 0x800-byte bit array that is swapped per scope (`GameFlags_TestScopedBit` 0x209a088 -> `NormalizeId`, `EnterScopeForRead`, `TestBit`); scoped *bytes* (ops 4-6, 15-17, 26-28, cmd 0x107) live in the same storage at byte offset 0x800 + index. The used-flags of the 2,920 records are 979 / 949 / 986 heroine-scoped (Manaka / Rinko / Nene) and 6 global.

Operand conventions: `a`, `b` are the 2nd/3rd condition words. cmp(a) b: a=0 `value >= b`, a=1 `==`, a=2 `<=`.  The caller combines results as `acc &= (r0 & 1)` for every condition of a group, groups are OR-ed, and a group with no handler-backed condition does not count.

Verification: `tools/cond_check.py` runs the real ARM handler of every op against `tools/cond_eval.py` for every (op, a, b) in the data over 40 mocked game states (all 107 ops bit-exact), and `tools/cond_check_files.py` does the same for whole files through native `CondList_CollectPassingRecords` (6,612 evaluations, 0 mismatches; the mock replaces every leaf outside the module with a deterministic function of its arguments).

Cross-check: for 2478 of 2920 of the records the event's own script sets (cmd 0x55) the record's used-flag, confirming the record layout and the meaning of `flag`.
