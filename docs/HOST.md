# Headless script host

`engine/src/{machine,game,host}.rs` run a script event end to end without drawing or playing anything and emit a typed, timestamped
effect stream.  A front end (renderer, audio, UI) consumes the effects; the effect list is the contract between script logic and presentation.

## Layers
| module | role | verified against |
|---|---|---|
| `script.rs` | one SBIN file: container, instruction decoding, single-script VM | `tools/lpvm.py` (563,846 trace lines, all 16,332 entries) |
| `machine.rs` | cross-script machine: master-directory calls (op 0x16), return-by-id (0x14), root-register handoff, per-slot locals | `tools/event_trace.py` `TraceMachine` (741,078 trace lines over every directory event, `tools/machine_dump.py` vs `machine_dump`) |
| `game.rs` | script-visible state: scoped flags (id format in CONDITIONS.md), clamped byte counters, clock, `Rand_Next` LCG, heroine records | unit tests; formats from the verified condition engine |
| `host.rs` | command semantics + effects + timeline + voice lengths | unit tests with a tiny SBIN assembler; real-content integration tests; `host_survey` |

## Effects
`Dialogue{name,sub,text,mode,choice}`, `Voice`, `Face`, `FaceAfter`, `Motion`, `MotionQueue`, `Camera`, `Fade`, `Bgm`, `Se`, `Ambient`, `StopSeq`,
`StopAmbient`, `SetActor`, `ChangeScene`, `FlowDispatch`, `Flag`, `Counter`, `Wait`, `WaitForever`, `WaitSound`, `WaitFade`, `Yield`, `Query`, `CallEvent`,
`ReturnById`, `Ended`, `Stopped`, plus `Command{id,name,category,conf,args}` for every command without a typed effect (nothing is dropped silently).
The command table (`engine/data/commands.json`, generated by `tools/cmd_ref.py`) supplies names, categories, confidence tiers and which commands write the accumulator.

## Time
Script ticks ("updates" of the running scene, 3.8 display frames at 60 Hz, measured in `tools/cmd_timing.py`).  `wait n` adds n ticks; `wait(-1)` is
`WaitForever` (an external condition ends it); fades take their frame count and `wait for fade` (op 0x88) advances to the fade end; `wait for voice`
(cmd 3) advances to the end of the last voice clip, whose length comes from `Siren14Voice.vtb` (40 bytes per 20 ms frame).  Reading time for dialogue is the player's, not the script's.

## Queries and the player
Query commands (those that write the accumulator) are answered from `GameState` where modelled: `test_flag` (0x59), `rand` (0xa7), `get_current_slot` variants.
All others answer 0 and are tagged `modelled: false` in the effect stream.  A `Policy` supplies mode-2 choice answers (one-based result written to register 0) and
can override any query, so tests and the real UI use the same hook (`Scripted` is the batch implementation; `host_run --choose 2,1 --reply 0x59=1`).

## Survey (`host_survey CONTENT`)
All 16,332 directory events with default answers: **16,184 finish** (99.1%), 126,314 dialogue boxes, 1.1 M effects, about 19 hours of scripted time.
148 events block: 139 command loops and 9 step-limit polling loops, all in scenes that wait for input or native state (dream scenes `dream_wait_timer` /
`dream_input_state`, skinship touch scenes `cmd_096/097`, kiss, a few `yield / wait 15` waits).  These need their own scene models, not more script work.
Most-hit unmodelled queries: `cmd_097` (skinship), `skinship_reaction_line`, `is_proc_active`, `cmd_21d`, `cmd_03d`, `cmd_1c8`, `char_bgm_record`.

## Not yet in the host
Event selection (the 36-stage resolver and 107 condition ops exist verified in Python; port next), save state / stat growth after events, text variables `{vN}`
(only v0 = player name is set; v3 looks like the heroine's family name and v26 the name she calls the player, from save data), interactive scenes (dream, skinship, kiss, minigames),
and the scene player that turns effects into pictures and sound.

## Tools
`host_run CONTENT EVENT_ID [--choose N,N] [--seed S] [--reply CMD=VALUE] [--player NAME] [--quiet]` prints the transcript; `host_survey CONTENT` the corpus summary;
`machine_dump` / `tools/machine_dump.py` the differential check (part of `tools/loader_check.sh` once added).
